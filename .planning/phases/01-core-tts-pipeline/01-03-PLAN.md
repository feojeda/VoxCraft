1. **backend/workers/engine/base.py** — Abstract TTS engine interface:
   ```python
   from abc import ABC, abstractmethod
   from dataclasses import dataclass
   from pathlib import Path
   import numpy as np

   @dataclass
   class SynthesisResult:
       audio: np.ndarray       # Raw audio samples
       sample_rate: int        # Sample rate (24000 for Qwen3-TTS)
       duration_seconds: float

   class BaseTTSEngine(ABC):
       @abstractmethod
       def synthesize(self, text: str, speaker: str, language: str,
                      instruct: str = "") -> SynthesisResult:
           """Synthesize speech from text."""
           ...

       @abstractmethod
       def get_speakers(self) -> list[dict]:
           """Return list of available speakers."""
           ...

       @abstractmethod
       def get_supported_languages(self) -> list[str]:
           """Return list of supported language names."""
           ...
   ```

2. **backend/workers/engine/qwen.py** — Qwen3-TTS adapter:
   - Loads model lazily via ModelManager
   - `synthesize()` calls `model.generate_custom_voice(text, language, speaker, instruct)`
   - Returns `SynthesisResult` with numpy audio array and sample rate
   - Wraps inference in `torch.inference_mode()` per F-06
   - Calls `torch.cuda.empty_cache()` after each synthesis
   - Maps speaker IDs to proper capitalization for Qwen3-TTS API

3. **backend/workers/engine/model_manager.py** — Singleton model loader:
   - `ModelManager` class holds the loaded Qwen3-TTS model
   - `get_engine()` returns `QwenTTSEngine` instance (lazy-loads model on first call)
   - Uses Celery `worker_process_init` signal to pre-load model at startup
   - Runs a dummy inference at startup to warm up CUDA kernels (prevents 30s delay on first real request)
   - GPU cleanup: `torch.cuda.empty_cache()` after each synthesis
   - `get_model_manager()` function returns singleton instance

   Model loading (per F-01):
   ```python
   from qwen_tts import Qwen3TTSModel
   import torch

   model = Qwen3TTSModel.from_pretrained(
       "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
       device_map=settings.GPU_DEVICE,
       dtype=torch.bfloat16,
       attn_implementation="flash_attention_2",
   )
   ```

   Speed-to-instruct mapping (per F-02):
   ```python
   def speed_to_instruct(speed: float) -> str:
       if speed <= 0.7: return "Speak very slowly"
       elif speed <= 0.9: return "Speak slowly"
       elif speed <= 1.1: return ""
       elif speed <= 1.3: return "Speak slightly faster"
       elif speed <= 1.6: return "Speak faster"
       else: return "Speak very fast"
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → POST /api/generate | Untrusted text input, speaker selection |
| API → Celery | Task dispatch (internal, trusted) |
| Celery → GPU | Model inference (internal, trusted) |
| User → GET /api/audio/* | Audio file download (public) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | POST /api/generate text field | mitigate | Pydantic validates text length (1-50000), strip HTML tags in preprocessing before sending to model |
| T-03-02 | Denial of Service | Long text generation | mitigate | Text length capped at 50000 chars; task_soft_time_limit=300s prevents infinite GPU use |
| T-03-03 | Denial of Service | Job polling | accept | Lightweight DB read; will add rate limiting in Phase 3 |
| T-03-04 | Information Disclosure | Audio file URLs | accept | Job IDs are UUIDs (non-guessable); no auth in Phase 1 (public tool) |
| T-03-05 | Tampering | Speaker parameter | mitigate | Validate speaker against known speaker list before dispatching task |
| T-03-06 | Elevation of Privilege | Celery task injection | accept | Redis broker is internal only (localhost), no external access |
</threat_model>
