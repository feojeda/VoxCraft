  <action>
Build the generation flow: button with loading state, job polling, progress display, and error handling.

1. **frontend/src/hooks/use-tts-generation.ts** — Core generation hook:
   - Uses TanStack Query for job creation and polling
   - State machine: `idle` → `creating` → `polling` → `completed` | `failed`
   - `generate()` function:
     a. Validate input (text non-empty, speaker selected)
     b. Call `createTTSJob({ text, speaker, speed })` — returns job_id
     c. Start polling `getJobStatus(job_id)` every 2 seconds
     d. On `completed`: stop polling, return audio URLs
     e. On `failed`: stop polling, return error message
   - Polling: TanStack Query `useQuery` with `refetchInterval` that stops when job is terminal
   - Return: `{ generate, status, progress, audioUrls, error, isGenerating }`
   - Each new generation replaces previous (per D-14)

2. **frontend/src/components/generate-button.tsx** — Per D-17, D-18:
   - States:
     - Default: "Generate Speech" with Play icon
     - Generating: "Generating..." with spinning Loader icon, disabled (D-17)
     - Disabled: when text is empty or no speaker selected
   - Button styling: accent background, full width, rounded, large text
   - Disabled styling: muted, cursor-not-allowed
   - No cancel button (D-18)
   - Props: `onClick: () => void`, `isGenerating: boolean`, `disabled: boolean`

3. **frontend/src/components/progress-bar.tsx** — Per D-08, D-10:
