       language: Mapped[str] = mapped_column(String, default="auto")
       speaker: Mapped[str] = mapped_column(String)
       speed: Mapped[float] = mapped_column(Float, default=1.0)
       instruct: Mapped[str | None] = mapped_column(String, nullable=True)
       audio_wav_path: Mapped[str | None] = mapped_column(String, nullable=True)
       audio_mp3_path: Mapped[str | None] = mapped_column(String, nullable=True)
       error_message: Mapped[str | None] = mapped_column(Text, nullable=True)
       created_at: Mapped[datetime] = mapped_column(default=func.now())

1. **backend/workers/celery_app.py** — Celery app with production-ready settings:
   ```python
   from celery import Celery
   from app.config import settings

   celery_app = Celery("ttsqwen")

   celery_app.conf.update(
       broker_url=settings.CELERY_BROKER_URL,
       result_backend=settings.CELERY_RESULT_BACKEND,
       task_serializer="json",
       result_serializer="json",
       accept_content=["json"],
       worker_concurrency=settings.WORKER_CONCURRENCY,  # 1 for GPU
       worker_prefetch_multiplier=1,
       task_soft_time_limit=settings.TASK_SOFT_TIME_LIMIT,  # 300s
       task_time_limit=settings.TASK_TIME_LIMIT,  # 600s
       worker_max_tasks_per_child=50,  # Recycle to prevent VRAM leaks
       task_routes={
           "workers.tasks.tts_generate": {"queue": "tts"},
       },
       visibility_timeout=720,  # > task_time_limit to prevent re-queuing
   )

   # Auto-discover tasks in workers/tasks/ directory
   celery_app.autodiscover_tasks(["workers.tasks"])
   ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → API | Public FastAPI endpoint accepting untrusted input |
| API → Redis | Internal broker communication (localhost only in dev) |
| API → SQLite | Internal database (localhost only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | POST /api/generate | mitigate | Pydantic validates text length (max 50000), speaker enum, speed range (0.5-2.0) |
| T-01-02 | Denial of Service | POST /api/generate | mitigate | Input length limit enforced at schema level; Celery queue prevents API blocking |
| T-01-03 | Information Disclosure | GET /api/jobs/{id} | accept | Job IDs are UUIDs (non-guessable), no auth in Phase 1 (public app), audio is public |
| T-01-04 | Tampering | CORS configuration | mitigate | Restrict origins to frontend dev server (localhost:3000), not wildcard |
</threat_model>
