   - Stage 2 (runtime): Copy installed packages + app code
   - Expose port 8000

   - Install system deps: `ffmpeg` (for audio conversion), `libsndfile1` (for soundfile)

   - Note in comments: "GPU inference requires NVIDIA Container Toolkit + host GPU. For GPU-less dev, worker runs on host."

2. **frontend/Dockerfile** — Multi-stage Next.js build:
   - Stage 1 (deps): Node.js 20-alpine, install dependencies
   - Stage 2 (builder): Copy source, build Next.js
   - Stage 3 (runner): Node.js 20-alpine, copy standalone output
   - Expose port 3000
   - CMD: `node server.js` (Next.js standalone output)
   - Set `NEXT_PUBLIC_API_URL` at build time (or runtime env)

3. **docker-compose.yml** — Full stack (update from Plan 01):
   - `api` service: build `backend/`, port 8000, depends_on redis, env_file .env
   - `worker` service: build `backend/`, command `celery -A workers.celery_app worker --loglevel=info --queues=tts`, depends_on redis, env_file .env
   - `redis` service: `redis:7-alpine`, port 6379, volume for persistence
   - `frontend` service: build `frontend/`, port 3000, depends_on api, environment: `NEXT_PUBLIC_API_URL=http://api:8000`
   - `volumes`: `audio_output` for generated files, `redis_data` for Redis
   - Networks: all services on same network
   - Add `.env` file reference for configuration
