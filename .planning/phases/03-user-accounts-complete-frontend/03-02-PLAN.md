## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Spoofing | localStorage token | mitigate | Use httpOnly cookie instead of localStorage; no JavaScript access to token |
| T-03-08 | Info Disclosure | Token in transit | mitigate | Cookie uses `Secure` flag in production; `SameSite=Lax` prevents CSRF on cross-origin POSTs |
| T-03-09 | Tampering | Route bypass | mitigate | Middleware redirects missing-cookie requests; API validates token independently |
| T-03-10 | Denial of Service | Redirect loops | accept | Logic ensures /login and /register are public; authenticated users on /login are sent to / |
</threat_model>
