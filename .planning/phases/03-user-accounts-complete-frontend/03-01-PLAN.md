Returns `UserResponse`. Return 401 on bad credentials.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | Auth tokens | mitigate | JWT signed with SECRET_KEY using HS256; expiration enforced via `exp` claim |
| T-03-02 | Tampering | Password storage | mitigate | bcrypt hashing via passlib with default rounds; never store plaintext |
| T-03-03 | Info Disclosure | Audio file access | mitigate | Audio routes verify `job.user_id == current_user.id` before serving files |
| T-03-04 | Info Disclosure | Job/preset data | mitigate | All list/detail endpoints filter queries by `user_id` |
| T-03-05 | Denial of Service | Login brute force | accept | No rate limiting in v1; add in future if needed (low-value target) |
| T-03-06 | Elevation of Privilege | Admin functions | accept | No admin endpoints exist in this phase |
